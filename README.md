# University Guide Marketplace 🎓

**Платформа для поиска зарубежных университетов и прямого общения с настоящими студентами и выпускниками (без дорогих комиссий агентств).**

## О проекте

Школьники и абитуриенты из Таджикистана и стран СНГ, которые хотят поступить в университеты Малайзии, Китая, Италии, Турции, Венгрии и других стран, могут:
- Узнать, **как поступить сразу после 11 класса**;
- Посмотреть **список нужных документов**, правила получения **студенческой визы** и **реальную стоимость проживания**;
- Найти **полные (100%) и частичные стипендии** с дедлайнами;
- Написать напрямую **проверенным студентам и выпускникам (Guides)** из этого университета.

---

## Три роли пользователей

| Роль | Логин (демо) | Пароль | Возможности |
| :--- | :--- | :--- | :--- |
| **1. Applicant (Абитуриент)** | `daler_applicant` | `student123` | Ищет университеты, изучает стипендии, выбирает гидов и переписывается с ними |
| **2. Guide (Гид / Наставник)** | `farzona_malaysia` | `guide123` | Заполняет профиль студента/выпускника, проходит верификацию, отвечает абитуриентам |
| **3. Admin (Администратор)** | `admin` | `admin123` | Проверяет и верифицирует гидов (`Verified`), подтверждает вузы, модерирует платформу |

*(Также в верхней панели сайта доступны кнопки быстрого входа в 1 клик за любую из 3 ролей!)*

---

## Стек технологий

- **Backend:** Python, Django 5
- **База данных:** SQLite (`db.sqlite3`)
- **Frontend:** HTML5, CSS3 (адаптивный дизайн), JavaScript
- **Модели БД:** `User`, `University`, `GuideProfile`, `Scholarship`, `Message`

---

## Как запустить проект

```bash
cd university_guide_marketplace
python manage.py migrate
python manage.py seed_data
python manage.py runserver
```

После запуска откройте в браузере: `http://127.0.0.1:8000/`
